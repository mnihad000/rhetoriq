# Legacy SaaS Removal

The hackathon implementation included integrations with Browserbase, Arize, Band, Redis Cloud, Gemini, Groq, and third-party search providers. These integrations are legacy implementation details and are not part of the RhetoriQ target documentation.

The next implementation phase will remove their dependencies, configuration, routes, and integration code. Until then, they may remain in the current codebase for compatibility, but they are not required by the target architecture described in this repository.

This document intentionally records the transition without presenting any of those providers as a product capability or endorsement.
